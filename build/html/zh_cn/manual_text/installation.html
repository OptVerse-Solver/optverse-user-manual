安装说明¶

支持平台¶

数学规划求解器与约束规划求解器 目前支持Linux系统平台，在以下系统测试可正常运行：

  • Ubuntu: Ubuntu 18.04, Ubuntu 20.04, Ubuntu 22.04

  • CentOS: CentOS 8, CentOS 9

  • 低版本Linux系统需要满足 glibc >= 2.33 和 libstdc++ >= 6.0.26

  • Python版本需要满足在3.10和3.13之间

获取渠道¶

线下版本¶

  • 软件安装包: 用户可联系 天筹求解器团队 获取，我们会有专人与您联系。

安装指南¶

线下版本安装¶

  1. 将求解器安装包 optverse.x.x.x.tar.gz 拷贝到指定路径(如 /opt/ ). 以下假设路径为 <installdir> .

  2. 解压缩安装包：

tar -xzvf optverse.x.x.x.tar.gz

这将创建一个新的路径 <installdir>/optverse ，路径结构为：

./
├── bin/
│   └── optverse
├── dist/
│   ├── optvpy-X.X.X-cp310-cp310-linux_x86_64.whl
│   ├── optvpy-X.X.X-cp311-cp311-linux_x86_64.whl
│   ├── optvpy-X.X.X-cp312-cp312-linux_x86_64.whl
│   └── optvpy-X.X.X-cp313-cp313-linux_x86_64.whl
├── examples/
│   ├── c++/
│   │   ├── feasibility-relax.cpp
│   │   ├── lp-sensitivity-analysis.cpp
│   │   ├── lp1.cpp
│   │   ├── lp2.cpp
│   │   ├── lp3.cpp
│   │   ├── milp1.cpp
│   │   └── milp2.cpp
│   ├── CMakeLists.txt
│   ├── data/
│   │   ├── lp-example.lp
│   │   ├── milp-example.mps
│   │   └── testNetwork.mps
│   └── python/
│       ├── feasibility-relax.py
│       ├── lp-sensitivity-analysis.py
│       ├── lp1.py
│       ├── lp2.py
│       ├── lp3.py
│       ├── milp1.py
│       └── milp2.py
├── include/
│   └── optv_c++.h
└── lib/
   ├── libiomp5.so
   └── liboptverse.so

  1. 设置 LD_LIBRARY_PATH：

echo 'export LD_LIBRARY_PATH="<installdir>/optverse/lib:${LD_LIBRARY_PATH}"' >> ~/.bashrc
source ~/.bashrc

  1. 进入 <installdir>/optverse/bin 路径，执行 ./optverse --version，如果显示以下信息则说明求解器已成功安装：

OptVerse Optimizer version 3.6.0 (Internal Release)
Copyright (c) Huawei Technologies Co., Ltd. 2022-2023. All rights reserved.

注解

本产品将数学规划求解器与约束规划求解器统一集成于单一安装包，实现一次部署、双求解器就绪。

Python SDK安装指南¶

安装包支持同时安装数学规划求解器和约束规划求解器的 Python SDK。安装包中包含统一的 wheel 安装文件，安装命令如下：

pip3 install optvpy-x.x.x-cp3x-cp3xm-linux_x86_64.whl

使用许可获取¶

SDK需要使用许可(license)才能正常使用，请联系 天筹求解器团队 获取，我们会有专人与您联系。

License使用¶

  • 把license文件放在某个目录下，如 /opt/Optverse.lic

  • 将 OPTV_LICENSE_FILE 环境变量指向license文件: export OPTV_LICENSE_FILE=/opt/Optverse.lic

注解

将此变量导出到.bashrc文件中，可方便多次连续调用。

echo "export OPTV_LICENSE_FILE=/opt/Optverse.lic" >> ~/.bashrc
source ~/.bashrc
cd <installdir>/optverse/bin
./optverse ../examples/data/lp-example.lp
