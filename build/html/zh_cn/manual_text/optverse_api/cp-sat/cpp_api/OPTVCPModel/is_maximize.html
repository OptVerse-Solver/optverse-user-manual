IsMaximize()¶

检查模型是否最大化目标函数值。

OPTVCPModel::IsMaximize()¶
返回:

模型是否最大化目标函数值的标志。

返回值:

  • true – 模型最大化目标函数值。

  • false – 模型会最小化目标函数值或者没有设置目标函数。
