MIP_FOCUS 解策略¶

类型： int

MIP高层级的解策略。

默认值： 0

最小值： 0

最大值： 3

该参数控制MIP求解器的优先度策略，默认为均衡式，具体信息如下：

取值

描述

0

均衡式。

1

优先快速找到可行解。

2

优先证明最优性。

3

优先改善下界。
