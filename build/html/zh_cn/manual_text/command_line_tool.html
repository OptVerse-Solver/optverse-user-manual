命令行工具¶

使用方法¶

显示帮助及版本信息¶

用法：

optverse [flag]   # Display help or version information

可选flag详见 参数说明。

求解问题¶

用法：

optverse [options]* filename # Set solving parameters, read model file, and solve

可选求解参数列表见 参数说明。

当前支持的文件格式有：

  • .mps, .lp 文件格式

  • .gz, .z, .Z 压缩文件格式

  • .fzn 文件格式

注解

  • .fzn 文件不支持压缩格式。

  • 有关 .mps 格式的详细说明可参考 MPS格式文件说明,有关 .lp 格式的详细说明可参考 LP格式文件说明。

  • 有关 .fzn 格式的详细说明可参考 FZN格式文件说明。

参数说明¶

-h, --help

显示帮助信息。

-v, --version

显示版本信息。

--method=<int>

求解算法。

允许的取值:

取值

含义

-1

自动

0

原始单纯形方法

1

对偶单纯形方法

2

内点方法 (IPM)

3

确定性内点方法(deterministic IPM)

4

并发求解方法 (concurrent solver)
默认:

-1

--timeLimit=<double>

求解时间上限 (秒)。

取值范围:

\([0.0, 1.79769 \times 10^{308}]\)

默认:

\(1.79769 \times 10^{308}\)

--memLimit=<int>

求解内存上限 (MB)。

取值范围:

\([100, 2147483647]\)

默认:

\(2147483647\)

--threads=<int>

求解线程数。

取值范围:

\([1,\) 平台线程\(]\)

默认:

平台物理核数

--gap=<double>

MIP目标gap值。

取值范围:

\([0.0, 1.79769 \times 10^{308}]\)

默认:

\(0.0001\)

--logFile=<string>

求解日志路径。

默认:

./optv.log

--resultFile=<string>

解文件路径。

默认:

./<filename>.sol

  • 如果用户没有指定任何输入参数，将默认返回帮助信息。

  • 输入问题模型文件只能作为最后一个输入参数。

  • 如输入问题为 网络流规划问题, 求解器将自动调用网络流单纯形法（network simplex method）进行求解。

使用示例¶

  • 不输入任何参数，默认显示帮助信息

    ./optverse

  • 显示帮助信息

    ./optverse -h
./optverse --help

  • 显示版本信息

    ./optverse -v
./optverse --version

  • 按默认设置求解问题文件 test-problem.mps 中的问题。

    ./optverse test-problem.mps

  • 求解问题文件 test-problem.mps, 指定日志文件为 ./test-problem.log, 结果文件为 ./test-problem.sol。

    ./optverse --logFile=./test-problem.log --resultFile=./test-problem.sol test-problem.mps

  • 求解压缩格式问题文件 test-problem.mps.gz 并设置时间上限7200秒，内存使用上限32GB，目标gap值 0.01%，使用线程数4并行求解。

    ./optverse --timeLimit=7200 --memLimit=32768 --gap=0.0001 --threads=4 test-problem.mps.gz
