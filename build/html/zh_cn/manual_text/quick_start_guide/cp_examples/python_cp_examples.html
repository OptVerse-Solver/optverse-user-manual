Python接口¶

本节将通过一个简单的示例来演示约束规划求解器Python接口的使用。

这个示例将介绍如何：

  • 设置求解器参数

  • 构建模型

  • 将构建模型写入文件

  • 优化模型

  • 打印最优解信息

待求解问题的数学公式如下所示：

\[\begin{split}\text{minimize } & b_1 + b_2 + b_3 + b_4 + 2x_1 + 2x_2 \\ \text{subject to } & -x_1 + 4x_2 + 8 \leq 15 \\ & 3b_1 - b_2 + x_1 = [3, 4] \cup [6, 10] \cup [12, 14] \\ & b_1 \lor b_2 \lor b_4 \\ & \neg b_1 \land b_3 \\ & b_2 + b_3 \geq 1 \\ & b_2 + b_4 \leq 1 \\ & b_2 + b_4 = 1 \\ & b_1 \rightarrow b_4 \\ \text{where } & b_1, b_2, b_3, b_4 \in [0, 1] \\ & x_1 \in [2, 5] \\ & x_2 \in [1, 2] \cup [5, 7] \cup [15, 15] \\\end{split}\]
from optvpy import *

    # Create an environment
    env = OPTVEnv()

    env.Set(OPTVDblParam.CP_TIME_LIMIT, 7200)

    # Create an empty model
    model = OPTVCPModel(env)

    model.Set(OPTVIntParam.CP_THREADS, 12)

    b1 = model.NewBoolVar("b1")
    b2 = model.NewBoolVar("b2")
    b3 = model.NewBoolVar("b3")
    b4 = model.NewBoolVar("b4")
    x1 = model.NewIntVar(2, 5, "x1")
    # domain: [1, 2], [5, 7], [15, 15]
    x2 = model.NewIntVarFromDomain([1, 2, 5, 7, 15, 15], name="x2")
    c1 = model.NewConstant(11)

    lin0 = model.AddLinearConstraint(-x1 + 4 * x2 + c1 - 3 <= 15)
    # domain: [3, 4], [6, 10], [12, 14]
    domain = [3, 4, 6, 10, 12, 14]
    lin1 = model.AddLinearConstraintInDomain(3 * b1 - b2 + x1, domain)

    boolOr = model.AddBoolOr([b1, b2, b4])
    boolAnd = model.AddBoolAnd([~b1, b3])
    boolALO = model.AddAtLeastOne([b2, b3])
    boolAMO = model.AddAtMostOne([b2, b4])
    boolEO = model.AddExactlyOne([b2, b4])
    boolImpl = model.AddImplication([b1, b4])

    boolOr.OnlyEnforceIf(b3, b4)

    model.Write("cp.fzn")

    solver = OPTVCPSolver()
    status = solver.Solve(model)

    if status == OPTV_CP_UNKNOWN:
        print("Model is unknown.")
    elif status == OPTV_CP_MODEL_INVALID:
        print("Model is invalid.")
    elif status == OPTV_CP_FEASIBLE:
        print("Model is feasible.")
    elif status == OPTV_CP_INFEASIBLE:
        print("Model is infeasible.")
    elif status == OPTV_CP_OPTIMAL:
        objVal = solver.GetObjectiveValue()
        print("Optimal solution found. Best objective value: ", objVal)
        vars = [b1, b2, b3, b4, x1, x2]
        result = solver.GetValues(vars)
        print("Optimal solution found. Best solution: ")
        for i in range(len(result)):
            print(vars[i].GetName(), " ", result[i])
    elif status == OPTV_CP_USER_INTERRUPT:
        print("Solver was interrupted by the user.")

from optvpy import *

if __name__ == "__main__":
    # Create an environment
    env = OPTVEnv()
    env.Set(OPTVDblParam.CP_TIME_LIMIT, 7200)

    # Create an empty model
    model = OPTVCPModel(env)
    # After model construction: set parameters through model
    model.Set(OPTVIntParam.CP_THREADS, 12)

    # Add variables to the model
    b1 = model.NewBoolVar("b1")
    b2 = model.NewBoolVar("b2")
    b3 = model.NewBoolVar("b3")
    b4 = model.NewBoolVar("b4")
    x1 = model.NewIntVar(2, 5, "x1")
    # domain: [1, 2], [5, 7], [15, 15]
    x2 = model.NewIntVarFromDomain([1, 2, 5, 7, 15, 15], name="x2")
    c1 = model.NewConstant(11)

    # Add constraint to the model
    lin0 = model.AddLinearConstraint(-x1 + 4 * x2 + c1 - 3 <= 15)
    # domain: [3, 4], [6, 10], [12, 14]
    domain = [3, 4, 6, 10, 12, 14]
    lin1 = model.AddLinearConstraintInDomain(3 * b1 - b2 + x1, domain)

    boolOr = model.AddBoolOr([b1, b2, b4])
    boolAnd = model.AddBoolAnd([~b1, b3])
    boolALO = model.AddAtLeastOne([b2, b3])
    boolAMO = model.AddAtMostOne([b2, b4])
    boolEO = model.AddExactlyOne([b2, b4])
    boolImpl = model.AddImplication([b1, b4])

    boolOr.OnlyEnforceIf(b3, b4)

    model.Write("cp.fzn")
    solver = OPTVCPSolver()
    status = solver.Solve(model)

    if status == OPTV_CP_UNKNOWN:
        print("Model is unknown.")
    elif status == OPTV_CP_MODEL_INVALID:
        print("Model is invalid.")
    elif status == OPTV_CP_FEASIBLE:
        print("Model is feasible.")
    elif status == OPTV_CP_INFEASIBLE:
        print("Model is infeasible.")
    elif status == OPTV_CP_OPTIMAL:
        objVal = solver.GetObjectiveValue()
        print("Optimal solution found. Best objective value: ", objVal)
        vars = [b1, b2, b3, b4, x1, x2]
        result = solver.GetValues(vars)
        print("Optimal solution found. Best solution: ")
        for i in range(len(result)):
            print(vars[i].GetName(), " ", result[i])
    elif status == OPTV_CP_USER_INTERRUPT:
        print("Solver was interrupted by the user.")

引入模块¶

要使用Python 接口，首先要安装并引入模块 optvpy.

from optvpy import *

创建环境¶

第一步需要创建一个空的环境对象。

# Create an environment
env = OPTVEnv()

模型创建前的参数配置¶

若需要在调用 OPTVCPModel 构造函数 前 修改求解器参数，用户必须通过环境对象设置这些参数。 在本例中，我们展示了在创建模型对象前如何通过环境对象设置求解器的时限参数。

env.Set(OPTVDblParam.CP_TIME_LIMIT, 7200)

模型创建后的参数配置¶

若需要在调用 OPTVCPModel 构造函数 后 修改求解器参数，用户则必须通过模型对象设置这些参数。 在本例中，我们展示了如何通过模型对象设置线程数量。

model.Set(OPTVIntParam.CP_THREADS, 12)

创建模型¶

创建了环境后，下一步就是创建模型。 每个模型是一个优化问题，它由一组变量，一组约束和关联属性(变量边界、目标系数、约束右端项等)组成。

创建空模型¶

如果用户需要通过API一步一步构造模型，首先需要做的是创建一个空模型。

# Create an empty model
model = OPTVCPModel(env)

从模型文件加载¶

如果把 .mps [1] 、 .lp [2] 或 .fzn [3] 文件路径当做第二个参数传入，该文件则被读取，相应的模型可以通过API求解或修改。

env = OPTVEnv()
model = OPTVCPModel(env, fileName)
[1]

有关MPS格式的说明，请参见 文件格式。

[2]

有关LP格式的说明，请参见 文件格式。

[3]

有关FZN格式的说明，请参见 文件格式。

向模型中添加变量¶

如果上一步创建了一个空模型，那么用户 必须 向该模型中添加变量和约束后，才可以进行求解。 同样，也可以通过添加变量或约束来扩展从文件加载的模型。

可使用以下方法向模型中添加变量：

  • OPTVCPModel.NewIntVar()

  • OPTVCPModel.NewIntVarFromDomain()

  • OPTVCPModel.NewBoolVar()

  • OPTVCPModel.NewConstant()

b1 = model.NewBoolVar("b1")
b2 = model.NewBoolVar("b2")
b3 = model.NewBoolVar("b3")
b4 = model.NewBoolVar("b4")
x1 = model.NewIntVar(2, 5, "x1")
# domain: [1, 2], [5, 7], [15, 15]
x2 = model.NewIntVarFromDomain([1, 2, 5, 7, 15, 15], name="x2")
c1 = model.NewConstant(11)

向模型中添加约束¶

变量添加完成后，用户可以继续添加约束。 约束规划求解器支持以下类型的约束：

  • Linear

  • Boolean Or

  • Boolean And

  • Boolean Xor

  • Implication

  • At Least One

  • At Most One

  • Exactly One

  • Table

  • Interval

  • No Overlap

  • Cumulative

  • All Different。

lin0 = model.AddLinearConstraint(-x1 + 4 * x2 + c1 - 3 <= 15)
# domain: [3, 4], [6, 10], [12, 14]
domain = [3, 4, 6, 10, 12, 14]
lin1 = model.AddLinearConstraintInDomain(3 * b1 - b2 + x1, domain)

boolOr = model.AddBoolOr([b1, b2, b4])
boolAnd = model.AddBoolAnd([~b1, b3])
boolALO = model.AddAtLeastOne([b2, b3])
boolAMO = model.AddAtMostOne([b2, b4])
boolEO = model.AddExactlyOne([b2, b4])
boolImpl = model.AddImplication([b1, b4])

boolOr.OnlyEnforceIf(b3, b4)

求解模型¶

模型构建完成并设置好参数后，可以使用 OPTVCPSolver.Solve() 求解模型。 求解完成后，求解状态与求解结果将保存在 OPTVCPSolver 对象中。

solver = OPTVCPSolver()
status = solver.Solve(model)

查询求解结果¶

求解完成后，可以通过 OPTVCPSolver 访问以求解模型中的相关数据。 函数 OPTVCPSolver.Solve() 在求解完模型后会返回求解状态，用于判断是否找到可行解。 使用 OPTVCPSolver.GetObjectiveValue() 可以获取当前找到的最优目标值。 而 OPTVCPSolver.GetSolution() 、OPTVCPSolver.GetValue()、OPTVCPSolver.GetValues() 等方法可以获取变量的取值。

if status == OPTV_CP_UNKNOWN:
    print("Model is unknown.")
elif status == OPTV_CP_MODEL_INVALID:
    print("Model is invalid.")
elif status == OPTV_CP_FEASIBLE:
    print("Model is feasible.")
elif status == OPTV_CP_INFEASIBLE:
    print("Model is infeasible.")
elif status == OPTV_CP_OPTIMAL:
    objVal = solver.GetObjectiveValue()
    print("Optimal solution found. Best objective value: ", objVal)
    vars = [b1, b2, b3, b4, x1, x2]
    result = solver.GetValues(vars)
    print("Optimal solution found. Best solution: ")
    for i in range(len(result)):
        print(vars[i].GetName(), " ", result[i])
elif status == OPTV_CP_USER_INTERRUPT:
    print("Solver was interrupted by the user.")

只需进入 ${OPTV_HOME}/examples 路径并执行。

python3 cp.py
