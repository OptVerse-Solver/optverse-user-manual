C++ MP API¶

This section presents a simple C++ example to demonstrate how to write a program using the OptVerse MP Solver’s C++ API.

This example illustrates how to:

  • Set solver parameters

  • Construct a model

  • Write the constructed problem to file

  • Optimize the model

  • Print solution information

The mathematical formulation for the problem to be solved is as follows:

\[\begin{split}\begin{array}{lr@{}c@{}r@{}l} \text{minimize } & -x & {}-{14y}-{} & 6z, & \\ \text{subject to } & 2x & {}+{y}+{} & z & {}\le 3 \\ & & {}{3y}+{} & z & {}\le 6, \end{array}\\ \begin{array}{rl} 0 \leq x &\leq 1\\ 0 \leq y & \\ 0 \leq z &\leq 3\\ \end{array}\\ \begin{aligned} \text{where } && x,\ y \in \mathbb{Z},\ z \in \mathbb{R}. \end{aligned}\end{split}\]
#include "optv_c++.h"

        OPTVEnv env("milp1.log");

        env.Set(OPTVDblParam::TIME_LIMIT, 7200);

        OPTVModel model(env);

        model.Set(OPTVStrParam::RESULT_FILE, "milp1.sol");

        OPTVVar x = model.AddVar(0, 1, -1, OPTV_BINARY, "x");
        OPTVVar y = model.AddVar(0, OPTV_INF, -14, OPTV_INTEGER, "y");
        OPTVVar z = model.AddVar(0, 3, -6, OPTV_CONTINUOUS, "z");

        OPTVConstr c0 = model.AddConstr(2 * x + y + z, -OPTV_INF, 3, "c0");
        OPTVConstr c1 = model.AddConstr(3 * y + z, -OPTV_INF, 6, "c1");

        model.Write("milp1.lp");

        model.Optimize();

        if (model.Get(OPTVIntAttr::SOL_COUNT) > 0) {
            cout << "Model Status: " << model.Get(OPTVIntAttr::STATUS) << endl;
            cout << "Best solution: " << model.Get(OPTVDblAttr::OBJ_VAL) << endl;

            cout << "x = " << x.Get(OPTVDblAttr::X) << endl;
            cout << "y = " << model.GetVar(1).Get(OPTVDblAttr::X) << endl;
            cout << "z = " << model.GetVarByName("z").Get(OPTVDblAttr::X) << endl;
            cout << "c0 = " << model.GetConstr(0).Get(OPTVDblAttr::X) << endl;
            cout << "c1 = " << model.GetConstrByName("c1").Get(OPTVDblAttr::X) << endl;
        } else {
            cout << "No feasible solution available!" << endl;
        }

/*
 * Copyright (c) Huawei Technologies Co., Ltd. 2022-2023. All rights reserved.
 * Description: OptVerse c++ interface example - build and solve an MILP problem
 */
#include "optv_c++.h"
using namespace std;

int main()
{
    try {
        OPTVEnv env("milp1.log");
        // Before model construction: set parameters through environment
        env.Set(OPTVDblParam::TIME_LIMIT, 7200);

        OPTVModel model(env);
        // After model construction: set parameters through model
        model.Set(OPTVStrParam::RESULT_FILE, "milp1.sol");

        // Add variables to the model
        OPTVVar x = model.AddVar(0, 1, -1, OPTV_BINARY, "x");
        OPTVVar y = model.AddVar(0, OPTV_INF, -14, OPTV_INTEGER, "y");
        OPTVVar z = model.AddVar(0, 3, -6, OPTV_CONTINUOUS, "z");

        // Add constraint to the model
        OPTVConstr c0 = model.AddConstr(2 * x + y + z, -OPTV_INF, 3, "c0");
        OPTVConstr c1 = model.AddConstr(3 * y + z, -OPTV_INF, 6, "c1");

        model.Write("milp1.lp");
        model.Optimize();

        if (model.Get(OPTVIntAttr::SOL_COUNT) > 0) {
            cout << "Model Status: " << model.Get(OPTVIntAttr::STATUS) << endl;
            cout << "Best solution: " << model.Get(OPTVDblAttr::OBJ_VAL) << endl;

            cout << "x = " << x.Get(OPTVDblAttr::X) << endl;
            cout << "y = " << model.GetVar(1).Get(OPTVDblAttr::X) << endl;
            cout << "z = " << model.GetVarByName("z").Get(OPTVDblAttr::X) << endl;
            cout << "c0 = " << model.GetConstr(0).Get(OPTVDblAttr::X) << endl;
            cout << "c1 = " << model.GetConstrByName("c1").Get(OPTVDblAttr::X) << endl;
        } else {
            cout << "No feasible solution available!" << endl;
        }

    } catch (const OPTVException& e) {
        cout << e.GetErrorCode() << ": " << e.GetMessage() << endl;
    } catch (...) {
        cerr << "Unknown exception" << endl;
    }
    return 0;
}

Include the Header¶

To provide access to the C++ interface, include the header file optv_c++.h.

#include "optv_c++.h"

Create the Environment¶

The first step is to create the environment object. The name of the log file is set by providing it to the constructor.

OPTVEnv env("milp1.log");

Configuring Parameters Before Model Construction¶

To edit solver parameters before calling the OPTVModel constructor, a user must set the parameter through the environment object. In this example, we demonstrate setting the solver time limit through the environment, prior to creation of the model object.

env.Set(OPTVDblParam::TIME_LIMIT, 7200);

Configuring Parameters After Model Construction¶

To edit solver parameters after calling the OPTVModel constructor, a user must set the parameter through the model object. In this example, we demonstrate setting the solution file through the model.

model.Set(OPTVStrParam::RESULT_FILE, "milp1.sol");

Creating the Model¶

After creating the environment, the next step is to create the model. Each OptVerse model is an optimization problem consisting of a set of variables, a set of constraints, and associated attributes (i.e. variable or constraint bounds, solution status, variable or constraint names, etc.).

Construct An Empty Model¶

If a user wishes to construct a model from scratch using API calls, they will first need to create an empty model.

OPTVModel model(env);

Loading Model from File¶

If the .mps [1] or .lp [2] extension is passed as the second parameter, the problem file is read. This allows solving or modifying a pre-existing model through the API.

OPTVEnv env("fileRead.log");
OPTVModel model(env, fileName);

For more details regarding this mode, refer to the example milp2.cpp

[1]

 For a description of the MPS format, see File Formats.

[2]

 For a description of the LP format, see File Formats.

Add Variables to Model¶

If an empty model was created in the previous step, variables and constraints must be added to the model before it can be solved. Alternatively, a model loaded from a file can be expanded through the addition of variables or constraints. The OPTVModel::AddVar() method allows adding a variable to a model object. The first and second parameters are the lower and upper bounds respectively. The third parameter is the objective coefficient. The fourth parameter is the variable type, one of: OPTV_CONTINUOUS, OPTV_INTEGER, or OPTV_BINARY. The fifth parameter is the name.

OPTVVar x = model.AddVar(0, 1, -1, OPTV_BINARY, "x");
OPTVVar y = model.AddVar(0, OPTV_INF, -14, OPTV_INTEGER, "y");
OPTVVar z = model.AddVar(0, 3, -6, OPTV_CONTINUOUS, "z");

If all created variables are OPTV_CONTINUOUS, the model is an LP problem, and the program automatically invokes the linear programming algorithm to solve the problem. For details, see the sample code lp1.cpp.

Add Constraints to Model¶

After adding variables, a user may now add constraints to the model. In the OptVerse API, constraint expressions are written as double-sided. This means the user must provide both lower and upper bounds to the constraint object upon creation. The first parameter is the constraint expression of type OPTVLinExpr. The second parameter and third parameters are the lower and upper bounds respectively. The fourth parameter is the name of the constraint.

OPTVConstr c0 = model.AddConstr(2 * x + y + z, -OPTV_INF, 3, "c0");
OPTVConstr c1 = model.AddConstr(3 * y + z, -OPTV_INF, 6, "c1");

Model Optimization¶

Once the model is constructed and any necessary parameters have been set, the model can be solved by invoking OPTVModel::Optimize(). After optimization, the solution status and optimal solution are saved in the OPTVModel object.

model.Optimize();

Querying the Solution¶

To output the solution after optimization, the OPTVModel::Get() method can be used to query various attributes of the model. First, we check the model attribute OPTVIntAttr::SOL_COUNT to determine if a feasible solution has been found. Next, we demonstrate querying the model status through OPTVIntAttr::STATUS. We obtain the best found objective value by using OPTVDblAttr::OBJ_VAL. Finally, we demonstrate three ways in which the value of a variable or constraint can be obtained.

if (model.Get(OPTVIntAttr::SOL_COUNT) > 0) {
    cout << "Model Status: " << model.Get(OPTVIntAttr::STATUS) << endl;
    cout << "Best solution: " << model.Get(OPTVDblAttr::OBJ_VAL) << endl;

    cout << "x = " << x.Get(OPTVDblAttr::X) << endl;
    cout << "y = " << model.GetVar(1).Get(OPTVDblAttr::X) << endl;
    cout << "z = " << model.GetVarByName("z").Get(OPTVDblAttr::X) << endl;
    cout << "c0 = " << model.GetConstr(0).Get(OPTVDblAttr::X) << endl;
    cout << "c1 = " << model.GetConstrByName("c1").Get(OPTVDblAttr::X) << endl;
} else {
    cout << "No feasible solution available!" << endl;
}

Compiling and Running¶

Several example files for the mathematical programming solver have been provided in ${OPTV_HOME}/examples/c++ along with the CMake file for compiling the examples on Linux.

To compile and run the examples, go to the ${OPTV_HOME}/examples directory and execute the following:

mkdir build && cd build
cmake ..
make -j $(nproc)

After compilation, the example from this section can be run by calling:

./milp1

If a user already has a problem in the form of an .mps or .lp file, they can optimize and check the objective and status through:

./milp2 xxx.mps
