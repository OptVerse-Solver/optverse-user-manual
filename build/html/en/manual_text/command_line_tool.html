Command Line Tools¶

OptVerse Solver Command Line Tool Usage¶

Displaying Help and Version Information¶

Usage:

optverse [flag]   # Display help or version information

Optional flags are detailed in the parameter description.

Solving Problems¶

Usage:

optverse [options]* filename # Set solving parameters, read model file, and solve

The optional solving parameter list can be found in parameter description.

Currently supported file formats include:

  • .mps, .lp Supported problem formats

  • .gz, .z, .Z Supported compressed formats

  • .fzn Supported problem formats

Note

  • .fzn format does not support compression.

  • For detailed information about the .mps format, refer to the MPS description, and for .lp format, refer to the LP description.

  • For the .fzn format, refer to the FZN description.

Parameter Description¶

-h, --help

Display help information.

-v, --version

Display version information.

--method=<int>

Solver algorithm.

Allowed values:

Value

Meaning

-1

Auto

0

Primal simplex

1

Dual simplex

2

Interior-point (IPM)

3

Deterministic IPM

4

Concurrent
Default:

-1

--timeLimit=<double>

Solver time limit (sec).

Range:

\([0.0, 1.79769 \times 10^{308}]\)

Default:

\(1.79769 \times 10^{308}\)

--memLimit=<int>

Solver memory limit (MB).

Range:

\([100, 2147483647]\)

Default:

\(2147483647\)

--threads=<int>

Solver threads.

Range:

\([1,\) platform threads\(]\)

Default:

Platform physical cores

--gap=<double>

MIP target gap.

Range:

\([0.0, 1.79769 \times 10^{308}]\)

Default:

\(0.0001\)

--logFile=<string>

Solver log path.

Default:

"./optv.log"

--resultFile=<string>

Solution file path.

Default:

"./<filename>.sol"

  • If no input parameters are specified, the default behaviour is to display help information.

  • The problem model file must be specified as the last input parameter.

  • For Network Flow Problems, the OptVerse solver will automatically use the network simplex method for solving.

Usage Examples¶

  • If no parameter is specified, the help information is displayed by default

    ./optverse

  • Display help information

    ./optverse -h
./optverse --help

  • Display version information

    ./optverse -v
./optverse --version

  • Solve the problem in the file test-problem.mps with default settings.

    ./optverse test-problem.mps

  • Solve the problem in the file test-problem.mps, specifying the log file as ./test-problem.log, and the result file as ./test-problem.sol.

    ./optverse --logFile=./test-problem.log --resultFile=./test-problem.sol test-problem.mps

  • Solve the compressed format problem file test-problem.mps.gz, setting a time limit of 7200 seconds, a memory limit of 32GB, a target gap of 0.01%, and using 4 threads for parallel solving.

    ./optverse --timeLimit=7200 --memLimit=32768 --gap=0.0001 --threads=4 test-problem.mps.gz

./optverse --resultFile=lp-example.sol examples/data/lp-example.lp

The obtained log is as follows:

Set parameter "resultFile" to "lp-example.sol"
OptVerse Optimizer version "3.6.0"

Presolve problem

After presolve:
  4 rows, 12 columns and 12 nonzeros

     Time    Iteration     Objective   Primal Num.Inf.  Dual Num.Inf.
     0.0s            0  0.000000e+00                4              0
     0.0s            4  1.380000e+02                0              0

Postsolving
Postsolve finished

     Time    Iteration     Objective   Primal Num.Inf.  Dual Num.Inf.
     0.0s            0  1.380000e+02                0              0

Solve results
  Status               Optimal solution found
  Objective            1.380000000000e+02
  Simplex iteration    4
  Time                 0.01

Write best solution /home/solver/optverse/lp-example.sol

The preceding logs contain the following information:

  • Parameter settings, including logFile and resultFile. For details about parameters, see OptVerse MP Parameters

  • Version and copyright information.

  • Problem read time.

  • Problem information, including the number of rows, number of columns, and number of non-zero elements.

  • Preprocessing time and problem scale after preprocessing, including the number of new rows, columns, and non-zero elements.

  • Simplex algorithm iteration log, such as time, number of iteration steps, current target value, and violation of primal and dual feasibility.

  • Post-processing information.

  • Overview of solution results, including:

    • Solution status, for example, “Optimal solution found”, “Problem is infeasible”, “Problem is unbounded”, “Time limit reached”, “Numerical error”, “Symbolic error”, “Unknown”

    • Optimal target value

    • Total number of iterations

    • Total time elapsed

  • Alarm error information such as warnings and errors.
