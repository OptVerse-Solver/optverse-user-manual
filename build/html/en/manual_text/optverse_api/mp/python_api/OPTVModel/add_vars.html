AddVars()¶

Add multiple variables to the model.

OPTVModel.AddVars(lb, ub, obj, vtype, names, count=None)¶

This function will add multiple variables to the model. In most circumstances, the difference is negligible, but when adding many elements at once, this form is preferred.

Parameters:

  • lb (list[float]) – List of variable lower bounds.

  • ub (list[float]) – List of variable upper bounds.

  • obj (list[float]) – List of linear coefficients in objective function.

  • vtype (list[str]) – List of variable types. One of OPTV_CONTINUOUS, OPTV_INTEGER, OPTV_BINARY.

  • names (list[str]) – List of variable names.

  • count (int) – [optional, defaults to length of parameters] Number of variables to be added to the model. Historically, this was a required parameter. However, past v1.2.6 users are encouraged to omit this parameter. If the count parameter is omitted, it will be inferred from the size of the other parameters.

Returns:

List of variables added to the model.

Return type:

list[OPTVVar]

Raises:

OPTVErrCode.INVALID_ARGUMENT – Unknown variable type, name is empty, numeric value is NaN, or a variable with a name in names already exists in the model.

Example:
# add multiple variables
model.AddVars([0]*3, [1]*3, [0]*3, [OPTV_BINARY]*3, [col_x, col_y, col_z], name=["x", "y", "z"])
OPTVModel.AddVars(lb, ub, obj, vtype, col, names, count=None)

This function will add multiple variables to the model, allowing to set coefficients for pre-existing constraints. In most circumstances, the difference is negligible, but when adding many elements at once, this form is preferred.

Parameters:

  • lb (list[float]) – List of variable lower bounds.

  • ub (list[float]) – List of variable upper bounds.

  • obj (list[float]) – List of linear coefficients in objective function.

  • type (list[str]) – List of variable types. One of OPTV_CONTINUOUS, OPTV_INTEGER, OPTV_BINARY.

  • col (list[OPTVColumn]) – Column objects.

  • names (list[str]) – List of variable names.

  • count (int) – Number of variables to be added to the model.

Returns:

List of variables added to the model.

Return type:

list[OPTVVar]

Raises:

OPTVErrCode.INVALID_ARGUMENT – Unknown variable type, names is empty, numeric value is NaN, or a variable with a name in names already exists in the model.

Example:
# add multiple variables and set coefficients for pre-existing constraints
col_x = OPTVColumn()
col_x.addTerm(1, c0)
col_y = OPTVColumn()
col_y.addTerm(1, c0)
col_z = OPTVColumn()
col_z.addTerm(1, c0)
model.AddVars([0]*3, [1]*3, [0]*3, [OPTV_BINARY]*3, [col_x, col_y, col_z], name=["x", "y", "z"])
OPTVModel.AddVars(*indices, lb=0.0, ub=OPTV_INF, obj=0.0, vtype=OPTV_CONTINUOUS, col=None, names='', count=None)

This function will add multiple variables to the model, allowing to set coefficients for pre-existing constraints.

It returns a OPTVTupleDict object that holds the variables created. The keys in the OPTVTupleDict object correspond to the values in the indices arguments. Multiple argument forms are supported, as detailed in the following section.

The first arguments specify the indices that will serve as keys for accessing the variables in the returned OPTVTupleDict. In its simplest form, you provide one or more integer values, and the method creates a multi-dimensional array of variables, analogous to a dense array in traditional programming. For example, x = model.AddVars(2, 2, name="x") creates four variables, with names: x_0_0, x_0_1, x_1_0, x_1_1.

When lists of immutable objects are provided, variables are created for all combinations of their elements. For example, x = model.AddVars([3, 7], ['a', 'b', 'c'], name="x") creates six variables, with names: x_3_a, x_7_a, etc.

You can also provide a custom list of tuples as indices. For example, x = model.addVars([(3,'a'), (3,'b'), (7,'b'), (7,'c')], name="x") creates variables accessible in the same way as in the previous example (e.g., x_3_a, x_7_c, etc.), but only for the specified combinations. This approach is commonly used to implement sparse indexing.

Note that while indices can be specified either as multiple lists or as a list of tuples, each element within an index must be a scalar value (such as an integer, float, or string). Composite values like tuples are not allowed as individual index components. The following example will raise an IndexError:

x = model.AddVars([((1, 3),'a'), (7,'a')], name="x")

y = model.AddVars([(1, 3), 7], ['a'], name="y")

Scalar values for keyword arguments like lb or obj apply uniformly to all variables. For example, lb=1.0 sets a lower bound of 1.0 for every variable created. The name parameter behaves differently: a scalar value (e.g., name="x") is interpreted as a prefix, and unique names are automatically generated (e.g., x_0, x_1, etc.). However, if the indices argument is a single list, you can provide a list of strings of the same length for the name parameter. Each string in the list will be used as the explicit name for the corresponding variable. For example, name=["varA", "varB", "varC"] assigns those exact names to the variables in order.

Parameters:

  • indices – Indices corresponding to the newly created variables.

  • lb – [optional] Variable lower bound(s).

  • ub – [optional] Variable upper bound(s).

  • obj – [optional] Linear coefficient(s) in objective function.

  • vtype – [optional] Variable type(s). One of OPTV_CONTINUOUS, OPTV_INTEGER, OPTV_BINARY.

  • col – [optional] Column object(s).

  • name – Variable name(s).

  • count – [optional] Number of variables to be added to the model.

Returns:

New OPTVTupleDict object that contains the new variables as values, using the provided indices as keys.

Return type:

OPTVTupleDict

Raises:

OPTVErrCode.INVALID_ARGUMENT – Unknown variable type, names is empty, numeric value is NaN, or a variable with a name in names already exists in the model.

Example:
# 3-D array of binary variables
x = model.AddVars(3, 4, 5, vtype=OPTV_BINARY)

# variables index by tuplelist
l = OPTVTupleList([(1, 2), (1, 3), (2, 3)])
y = model.addVars(l, ub=[1, 2, 3])

# variables with predetermined names
z = model.AddVars(3, name=["a","b","c"])
