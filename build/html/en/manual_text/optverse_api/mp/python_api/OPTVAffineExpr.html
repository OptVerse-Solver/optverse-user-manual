OPTVAffineExpr¶

class OPTVAffineExpr¶

The OPTVAffineExpr class serves as the foundation for constructing conic constraints by encapsulating the affine transformation \(Fx + g\). An OPTVAffineExpr object contains:

  • Linear coefficients: The sparse representation of matrix \(F\), storing non-zero coefficients and their corresponding variable indices in Coordinate (COO) sparse format. Affine expressions are constructed by adding rows of linear expressions (the COO storage is internal, users will provide data through SDK objects).

  • Model variables: The sparse representation of the vector \(x\). Users only need to provide the participating variables, through adding linear expression objects as rows.

  • Constant terms: The offset vector \(g\) that shifts the linear combination.

When creating an OPTVCone, the OPTVAffineExpr provides the mathematical structure (the affine transformation), while the cone type parameter specifies the geometric constraint \(C\) that the expression must satisfy. This separation allows for flexible composition of conic constraints from simpler affine building blocks.

See OPTVCone.
